# L2Web

A personal web application featuring a live high-precision clock, customizable name display, and modern dark glassmorphic styling.

## Features
- **Personal Space**: Customizable user name (default: 吳奕霆) with inline editing and local storage persistence.
- **Live Clock**: Precision real-time clock displaying hours, minutes, seconds, and a minute progress indicator.
- **12H / 24H Toggle**: Instant format switching with dynamic AM/PM badge.
- **Dynamic Greetings**: Context-aware greeting (Morning, Afternoon, Evening, Night) with weather/sky icons.
- **Dark Glassmorphism**: Frosted glass surface, glowing ambient orbs, and subtle 3D interactive cursor tilt.
- **Agent Skills**: Integrated with `frontend-design` skill from [agentic-awesome-skills](https://github.com/sickn33/agentic-awesome-skills).

## Tech Stack
- Pure HTML5, CSS3, and JavaScript (Vanilla ES6+).
- Google Fonts (`Outfit`, `JetBrains Mono`).

## Getting Started
Simply open `index.html` in any modern web browser or serve it locally:
```bash
python -m http.server 8080
```
Then visit [http://localhost:8080](http://localhost:8080).
